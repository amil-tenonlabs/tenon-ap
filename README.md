# tenon-ap

Accounts payable recipes and bot by Tenon Labs: Workato recipes, prompts and
reference documents for an email-triggered AP assistant for general
contractors, built alongside APM (`amil-tenonlabs/tenon-apm`).

Start with `CLAUDE.md` for how this repo works, `design/ap-bot-overview.md` for
what is proposed, and `TODO.md` for what is open.
